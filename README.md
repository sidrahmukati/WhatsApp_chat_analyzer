# Chat Analysis App

A Streamlit-based application that analyzes chat data and provides insights into messaging activity and user behavior.

## Features

* Analyze chat activity
* View messaging statistics
* Explore activity patterns
* Visualize chat data
* Filter and analyze individual users

## Technologies Used

* Python
* Streamlit
* Pandas
* NumPy
* Matplotlib
* Seaborn

## Project Structure

```text
├── app.py
├── helper.py
├── preprocessor.py
├── requirements.txt
├── .gitignore
└── README.md
```

## How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/sidrahmukati/WhatsApp_chat_analyzer.git
```

2. Install the required packages:

```bash
pip install -r requirements.txt
```

3. Run the Streamlit application:

```bash
streamlit run app.py
```

## Deployment

This application can be deployed using Streamlit Community Cloud by connecting the GitHub repository and selecting `app.py` as the main application file.
